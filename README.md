## Sobre mí

Desarrollador backend enfocado en **arquitectura de software**: diseño sistemas distribuidos y escalables con Arquitectura Hexagonal, Onion y DDD. Me interesa entender por qué las cosas funcionan antes de usarlas.

- Construyo plataformas institucionales y sistemas en tiempo real que están en producción.
- Recientemente impartí un curso de React — enseñar obliga a entender diferente.
- Prefiero código explícito sobre magia implícita.
